### Projects

**[Sanctions Network Mapper](github.com/mino6225/sanctions-network-mapper)**
Maps hidden connections between 19,015 OFAC-sanctioned entities via shared address analysis. Identified five distinct sanctions evasion networks including a 147-entity Iranian dark fleet cluster and a Russian real estate GmbH network. Built with Python, NetworkX, PyVis, pandas.

**[Eurasian Entity Risk Screener](github.com/mino6225/eurasian-risk-screener)**
Screens companies against 38,895 OFAC sanctioned entities and scores countries using six World Bank governance indicators. Produces CRITICAL/HIGH/MEDIUM/LOW risk classifications with composite scoring. Built with Python, pandas, NumPy.

**[Geopolitical News Sentiment Tracker](github.com/mino6225/geopolitical-news-sentiment)**
Pulls live international news via NewsAPI and runs VADER sentiment analysis across five high-risk countries. Tracks sentiment trends over time and produces a four-panel dashboard. Built with Python, VADER, NewsAPI, matplotlib.

**[Loan Default Prediction Model](github.com/mino6225/loan-default-predictor)**
Compares four ML classification algorithms — Logistic Regression, Decision Tree, Random Forest, XGBoost — with cross-validation and hyperparameter tuning. Key finding: credit history is the dominant predictive variable at ~92% denial rate without it. Built with Python, scikit-learn, pandas.

 **[AML Transaction Surveillance Engine](github.com/mino6225/aml-surveillance-engine)**
A rule-based suspicious activity detection system applying BSA/AML typologies including structuring detection, layering analysis, round-trip transaction identification, and high-risk jurisdiction flagging. Generates automated SAR-style summary reports.
